## Why svedocs

svedocs keeps the docs engine, default theme, deployment helpers, search, Ask AI, SEO, and OG image pipeline inside one Svelte-native framework package.

## What ships first

- A SvelteKit-first content pipeline.
- Tailwind CSS v4 theme tokens.
- Cloudflare-oriented build modes.
- MiniSearch local search, Algolia, Typesense, and Cloudflare/OpenAI-compatible Ask AI contracts.
