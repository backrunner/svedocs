# 更新日志

这个页面使用内建的单页布局。它不会显示文档侧栏，但仍会使用站点的元数据、搜索记录、OG 路由、主题控制和命令面板。

## 0.2.1 — 2026-09-07

- 本地搜索按需加载，默认主题的排名计算移入共享 Worker。
- 复用 Markdown 分析和未修改页面的编译结果，提供可选且有容量限制的公开 SSR HTML 缓存。
- 修复本地化导航、输入法确认和移动端搜索、弹窗交互。
- 统一 noindex、hreflang、sitemap、RSS 与 agent 发现规则，补充面包屑结构化数据及分享元数据。
- 分享图默认生成 PNG，支持长标题换行，固定图片 URL 重新验证缓存。

**升级说明：** PNG 在 Node 构建或预渲染阶段生成；边缘动态图片路由请显式选择 SVG。修改时间元数据和页面更新时间现在使用明确的 `updatedTime`，不再把文件系统时间当作内容日期。现有公开导入、页面字段和同步搜索接口保持可用。

## 2026-05-18

- 扩展导航、字体、圆角和代码主题配置。
- 增加 remark 与 rehype 的编译期 Markdown 插件钩子。
- 扩展 SEO 元数据，支持作者、发布时间和更新时间。
