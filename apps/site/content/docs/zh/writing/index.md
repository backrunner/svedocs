# 写作

svedocs 把正文和交互式作者体验放在同一个内容树里。大多数页面直接用 Markdown 写，需要交互示例时再切到 SVX 或 MDX 风格文件。

## 从这里开始

- [内容](/docs/zh/writing/content)
- [组件](/docs/zh/writing/components)

## 这一节会讲什么

- frontmatter、标题、描述和路由映射。
- 表格、任务列表、数学公式、代码元数据和提示块。
- 用 Svelte 组件写交互示例和局部布局。
